# alishdipani.github.io

Source of my personal website: **https://alishdipani.github.io/**

Built with [Astro](https://astro.build/) as a static site.

## Commands

- `npm install`: install dependencies (Node 24)
- `npm run dev`: local dev server at http://localhost:4321/
- `npm run build`: build the site into `dist/`
- `npm run check:urls`: check that every URL of the old site still works
- `npm run check:links`: check internal links and images (needs a build)

Publications come from `src/data/publications.bib` and blog posts from `src/content/blog/`.
