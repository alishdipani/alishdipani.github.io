## Text and structure

Body text is set in a single narrow column of about 65–70 characters per line. Each `##` heading starts a numbered section, and the marker above it ("01 / 06") is added automatically. Hovering over a heading shows its anchor link, so any section can be linked to directly.

### A third-level heading

Third-level headings divide a section without starting a new one; they get anchor links too, but no section marker. Inline `code`, **bold**, *italic* and [links](https://example.com) look like this.

<PullQuote>A pull quote lifts one sentence out of the text and sets it apart.</PullQuote>

The paragraph after a pull quote continues the argument. Pull quotes repeat text from the surrounding section rather than adding new content.

## Notes and citations

Footnotes use the normal Markdown syntax.[^1] On a computer, hovering over the number shows the note; on a phone, tapping it jumps to the list of notes at the end of the post.[^2]

Citations come from the post's own `.bib` file, written as `[@key]` in the text. A single source looks like this [@shannon1948], and several at once like this [@turing1950; @hubel1962]. Each citation gets a number in order of first use, a hover preview, and an entry in the reference list at the bottom. Citing a source again reuses its number [@shannon1948].

Sidenotes sit in the right margin on wide screens.<Sidenote>A sidenote is a short aside that doesn't need its own footnote. On phones it appears indented, right below the line it belongs to.</Sidenote> They suit short asides that the reader can take or leave without losing the thread.

[^1]: A footnote can hold a longer remark, a source, or a technical detail that would interrupt the text.
[^2]: Footnotes are numbered automatically and listed under "Footnotes" at the end of the post.

## Math and code

Math is written in LaTeX between double dollar signs, inline like $$e^{i\pi} + 1 = 0$$ or as a display block:

$$
H(X) = -\sum_{x} p(x) \log_2 p(x)
$$

Code blocks are highlighted, in light and dark colors that follow the page:

```python
def entropy(p):
    """Shannon entropy, in bits, of a discrete distribution p."""
    return -sum(q * math.log2(q) for q in p if q > 0)
```

## The end

The last paragraph of a post ends with an end mark, added automatically. After it come the footnotes and the references.
